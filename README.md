# Ball Territory Simulator

基于 Unity 2022.3.62f1c1 的球球领土战争首版原型。

## 当前功能

- 四个自动对战阵营：红队、蓝队、绿队、黄队
- 四个拥有独立血量的基地
- 128×128 领土网格
- 球球保持直线移动，碰到地图边界或其他球球时反弹
- 基础近距离攻击、生命值和死亡
- 球球碰撞敌方基地会扣除基地血量
- 基地会自动派出小球，也可以在界面中手动发球
- 领土、存活球数和击杀统计
- 暂停、继续、倍速和重新开始
- 只有基地血量归零才会淘汰阵营；只剩一个未摧毁基地时判定胜负

## 打开方式

使用 Unity 2022.3.62f1c1 打开本项目，进入 `Assets/Scenes/MainScene.unity`，点击 Play。

首版使用运行时生成的几何图形，不需要额外美术素材。

## 验证说明

已使用本机 C# 编译器检查全部脚本的语法及 UnityEngine API 引用。Unity 编辑器的无界面启动在当前电脑上停留在许可证/编辑器初始化阶段，因此首次运行请在 Unity Hub 中手动打开项目并点击 Play。
