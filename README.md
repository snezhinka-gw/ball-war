# Ball Territory Simulator

基于 Unity 2022.3.62f1c1 的球球领土战争首版原型。

## 当前功能

- 四个自动对战阵营：红队、蓝队、绿队、黄队
- 四个拥有独立血量的基地
- 256×256 领土网格
- 带阵营色边缘的固定圆形基地核心
- 基地核心上的匀速顺时针旋转射击器
- 球球保持直线移动，碰到地图边界或其他球球时反弹
- 基础近距离攻击、生命值和死亡
- 球球碰撞敌方基地会扣除基地血量
- 基地会自动派出小球，也可以在界面中手动发球
- 开始页面可调整球球数量、基地参数、射击器转速、基地位置和阵营颜色
- 领土、存活球数和击杀统计
- 暂停、继续、倍速和重新开始
- 只有基地血量归零才会淘汰阵营；只剩一个未摧毁基地时判定胜负

## 打开方式

使用 Unity 2022.3.62f1c1 打开本项目，进入 `Assets/Scenes/MainScene.unity`，点击 Play，在开始页面调整参数后点击“开始比赛”。

首版使用运行时生成的几何图形，不需要额外美术素材。

## Git 更新机制

项目已经初始化为 Git 仓库，并配置了自动更新钩子：

- 每次提交后自动把提交标题、时间和变更文件写入 `CHANGELOG.md`。
- 配置 `origin` 远程仓库后，每次提交会自动执行 `git push origin HEAD`。
- 也可以使用 `Tools/Publish-Update.ps1 -Summary "本次更新说明"` 完成暂存、提交和上传。

首次连接云仓库时，需要在本项目目录执行：

```powershell
git remote add origin <你的远程仓库地址>
git push -u origin main
```
