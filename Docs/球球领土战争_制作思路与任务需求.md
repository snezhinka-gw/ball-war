# 球球领土战争：制作思路与任务需求

本文件是项目内版本，内容与工作区中的需求文档保持同步。

当前阶段定位为：在 Unity 编辑器内运行的无人操作自动模拟小游戏。项目不做玩家直接操控，不做 Windows/WebGL/Android 打包；胜负唯一取决于四个基地的血量是否归零，球球只在碰到墙壁、其他球球或基地时改变方向。

完整需求文档位于工作区：

`outputs/球球领土战争_制作思路与任务需求.md`

本阶段的关键建议：

- 使用随机种子决定初始方向、出生微偏移和发球节奏。
- 增加初始球球数量和基地周期发球，设置活动球球上限。
- 用逐步提高发球频率的防僵局机制提高基地最终被碰撞的概率，但不直接指定胜者。
- 保留暂停、倍速、重开和统计信息等观战/调试功能。
